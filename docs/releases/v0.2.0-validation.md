# v0.2.0 发布前验证

## 根因与修复

刷新状态原先优先显示 `refreshing` 或读取错误，导致已有成功额度时用户看到“更新中/读取超时”，即使旧快照仍在内存中。现在有旧快照时优先展示“可能非最新”提醒，额度数据不会被失败请求清空；连续失败计数达到 3 次才进入连接异常。

## 已执行验证

- Release build：零警告、零错误。
- `QuotaChecks`：首个快照成功后连续失败，确认旧百分比保持不变；第 1、2 次失败显示“可能非最新”；第 3 次才显示“连接异常”。
- 协议握手、自动会员到期、错误分类、取消、语言切换、定时刷新和释放测试通过。
- UI 截图、标题栏、托盘/任务栏行为、角落吸附、最大化/还原、最小化和关闭测试通过。
- PowerShell UTF-8 BOM、`git diff --check` 通过。
