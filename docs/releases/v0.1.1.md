# v0.1.1

## 新功能

- 新增中文与 English 界面；默认使用简体中文。
- 主界面新增设置页：可手动刷新、选择刷新间隔、切换语言、设置开机启动，以及填写会员到期兜底日期。
- 默认启用当前用户开机启动；设置项使用 Windows 当前用户 Run 注册表，不要求管理员权限。
- 托盘菜单精简为“主界面”和“退出小组件”，双击托盘图标也可打开主界面。
- 会员时间中文格式更新为 `到期：yyyy/MM/dd HH:mm:ss(剩余N天N小时N分)`。

## 会员到期时间说明

- 小组件会优先读取 Codex 响应中名称明确的会员、订阅或套餐到期字段。
- 公开的 Codex app-server 协议目前没有保证提供此字段；缺失时可在设置页保存本地日期作为显示兜底。
- 不会把 5 小时/7 天额度重置时间或重置券的到期时间当作会员到期时间。

## 安装

- Windows 10/11 x64：下载 `codex-quota-widget-v0.1.1-windows-x64-setup.exe` 安装。
- 免安装：下载 ZIP，完整解压后运行 `CodexQuotaWidget.exe`。
- 两种包均自带 .NET 8 运行时；真实额度仍需要本机安装并登录 Codex。
