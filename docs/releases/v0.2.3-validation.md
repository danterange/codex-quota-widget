# v0.2.3 发布前验证

## 已实现

- 解析可用重置券中最早的到期时间，不记录券 ID、标题或说明。
- 成功刷新后记录本地成功时间，显示紧凑更新时间和完整悬浮提示。
- 从 5 小时、7 天、月度窗口中计算最早恢复时刻，Free 与付费套餐共用。

## 验证证据

- Free 协议夹具断言月度、余额、重置券最早到期时间独立解析。
- Free ViewModel 断言最早恢复、刚刚更新和重置券到期提示。
- Pro/Free 实际 WPF 截图分别为 320×226 与 320×185；窄/宽缩放、标题栏、托盘、任务栏隐藏和角落吸附回归通过。
- 本机真实 Free 只读验证通过；读取使用 app-server 账户/额度接口，不发起模型请求或重置。
