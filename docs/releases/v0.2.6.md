# Codex Quota Widget v0.2.6

## 直接重启 ChatGPT Desktop

- 标题栏的重启入口改为“重启 ChatGPT Desktop”。确认后会直接关闭并重新打开 ChatGPT Desktop，不再等待优雅退出、读取会话锁或运行 CLI 健康检查。
- 只会强制结束本次捕获且精确匹配 OpenAI.Codex 安装路径、PID 和创建时间的 Desktop 包内进程；Codex CLI、终端和其他程序不会被关闭。
- 重启前明确提示未保存内容和未完成回复可能丢失；本功能不保存或恢复会话。
- 状态提示支持辅助技术播报，并在启动新 Desktop 根进程后才报告成功。

## 玻璃主题

- 玻璃主题调整为外壳更透明、额度卡片更稳定的分层效果：背景可透出桌面轮廓，日期和百分比仍保持可读。
- 检测 Windows 的“透明效果”设置；系统关闭透明效果、高对比度或不支持 DWM 时自动使用实色回退，并在主题按钮提示原因。
