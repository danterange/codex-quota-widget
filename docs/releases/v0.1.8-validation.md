# v0.1.8 发布前验证

## 修复内容

用户反馈日期 ToolTip 在浅色默认样式下几乎没有可读文字。新增全局深色半透明 ToolTip 模板，使用亮色文字、边框、圆角和阴影；自动化 HelpText 仍验证完整日期存在。

新增标题栏角落吸附按钮。`WindowWorkArea.SnapToNearestCorner` 根据当前 HWND 所在显示器的工作区计算四个候选角落，选择距离当前位置最近的一项，并保留 2 DIP 间距。工作区自动排除任务栏，扩展屏负坐标由 Win32 monitor rect 支持。

## 本地验证

- Release build：零警告、零错误。
- QuotaChecks：协议、设置、日期、颜色阈值、错误恢复、单次失败不显示异常、定时刷新全部通过。
- Test-UiScreenshot：ToolTip HelpText 完整日期、SnapButton 存在且在置顶按钮左侧、吸附后两条工作区边缘约为 2px、最大化/还原/最小化/置顶/关闭全部通过。
- 截图已重新生成并人工查看 `dashboard.png`、`settings.png`、`narrow.png`、`wide.png` 和实际悬浮的 `tooltip2.png`；深色 ToolTip 已清晰显示完整到期时间和剩余时间，背景仍为深蓝紫半透明渐变，图标未裁切。
- PowerShell UTF-8 BOM、git diff 检查通过。
