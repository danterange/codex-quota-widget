# v0.1.4

## 界面改进

- 修复左侧图标栏被主内容区域遮挡的问题，确保刷新、设置和额度图标完整显示。
- 保持紧凑的自适应窗口布局，主界面与设置页在调整窗口大小后继续正确排列。
- 保留中文/English 双语界面、默认置顶、托盘菜单和到期时间倒计时显示。
- 安装器不再直接写入启动项，避免受限系统的注册表策略阻断安装；首次启动时由应用按默认设置管理当前用户启动项。

## 验证

- 通过 Release 编译与回归检查。
- 通过 UI 自动化和截图检查，确认图标完整、窗口可调整、设置页可切换。
- 安装包与便携 ZIP 均随本版本发布，并提供 SHA-256 校验文件。
