# Codex Quota Widget v0.1.8

## 角落吸附与清晰悬浮提示

- 在置顶按钮左侧新增“贴到最近角落”按钮，按当前位置自动吸附到当前显示器工作区的最近角落。
- 吸附边缘保留 2 像素，右下角以任务栏上方的工作区底边为准，支持扩展屏和负坐标。
- 日期完成时间悬浮提示改为深色半透明高对比度样式，修复浅色默认 ToolTip 导致文字看不清的问题。
- Acrylic 背景继续使用系统支持的 Desktop Acrylic，并降低渐变不透明度，让背景更有轻微透明感。
- 补充角落吸附、标题栏按钮、工作区边界和悬浮提示回归验证。

- UI 截图、角落吸附、最大化避开任务栏、最小化/还原、置顶和关闭行为测试通过。
