# Codex Quota Widget v0.2.4

## 主题与紧凑界面

- 新增夜间默认、白天和玻璃三种主题；主题按钮循环切换并保存偏好。
- Windows 11 使用 Acrylic 玻璃材质；旧系统和高对比度模式回退到可读的实色系统配色。
- 标题栏新增 Desktop 重启、主题和贴角入口，并为图标与关键信息文字补齐悬浮提示和辅助功能说明。
- 贴到最近角落时会先按当前内容恢复紧凑尺寸，再保留 2px 间距贴到所在显示器工作区；普通自由缩放仍可使用。
- 调整白天主题的额度色与悬浮提示文字对比度，避免黄色进度和日期 ToolTip 难以阅读。

## ChatGPT Desktop 优雅重启

- 新增仅针对 ChatGPT Desktop / OpenAI.Codex MSIX 的重启入口；不会关闭或恢复 `codex` CLI 会话。
- 重启前会检查精确包路径、PID/创建时间和最小会话候选快照；无法安全确认时拒绝关闭 Desktop。
- 默认只请求正常关闭。只有关闭超时后再次点击并在警告对话框明确确认，才会强制结束已捕获且精确匹配包路径的 Desktop 进程。
- 使用 PowerShell 7 监督器重新拉起 Desktop 并验证缓存 ChatGPT 登录。SSO、MFA、通行密钥和过期登录仍需要用户完成。

> 正在流式生成的 Desktop 回合没有可验证的公开无缝恢复接口。v0.2.4 仅记录可识别的活动会话候选并提示用户手动继续，不会宣称自动恢复未完成回合。

## 验证

- 离线协议、设置、Free 额度、失败保留、主题、重启报告关联和强制确认回归通过。
- 窗口壳和 UI 自动化覆盖三主题、真实桌面玻璃截图、日期 ToolTip、320/300/600 宽度、贴角自适应、置顶、最小化、最大化和关闭到托盘。
- 重启监督器的隔离模拟和真实 Desktop dry-run 通过；验收没有关闭或启动当前 Desktop。
