# v0.1.0

首个公开可用版本，后续会继续迭代。

## 下载与安装

- Windows 10/11 x64：下载 `codex-quota-widget-v0.1.0-windows-x64-setup.exe`，双击安装。
- 免安装：下载 ZIP，全部解压后运行 `CodexQuotaWidget.exe`。
- 两种分发均包含 .NET 8 桌面运行时，无需另装 SDK 或 .NET。
- 真实额度需要本机已安装并登录 Codex（ChatGPT 账号）；不包含任何账号凭据。

## 功能

- 桌面悬浮显示当前账号 5 小时/7 天剩余额度和重置倒计时。
- 托盘手动刷新、调整刷新间隔和退出。
- 新增统一程序、窗口、托盘及安装包图标。
- 当前用户安装、开始菜单入口、可选桌面快捷方式和卸载入口。

## 已知限制

- 暂仅提供 Windows x64 包；尚无程序内自动更新。
- 会员到期时间依赖 Codex 接口，未提供时显示未知。
- 安装包尚未使用代码签名证书，Windows 可能显示未知发布者提示。
- 后续更新请退出小组件，再安装新版；刷新间隔设置保留。

可使用 `SHA256SUMS.txt` 校验下载文件。
