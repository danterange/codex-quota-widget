# v0.1.9 发布前验证

## 变更

主窗口设置为 `ShowInTaskbar=false`，托盘仍由 `NotifyIcon` 唯一提供入口。保留托盘双击/菜单恢复、标题栏最小化和关闭隐藏行为；不改变额度、窗口样式或安装路径。

## 验证

- Release 编译通过，零警告、零错误。
- QuotaChecks 隔离窗口检查首次显示、设置页、最大化、还原和隐藏恢复均没有任务栏入口；托盘之外不创建 Shell 任务栏项。
- UI 自动化检查 `WS_EX_APPWINDOW` 未设置，同时继续通过置顶切换、角落吸附、最大化/还原、最小化/恢复和关闭。
- PowerShell UTF-8 BOM、`git diff --check` 和中文/英文截图检查通过。
- 新版发布后的安装器验收将使用 GitHub Actions 的干净 Windows 环境；本机当前安装目录保持不变。
