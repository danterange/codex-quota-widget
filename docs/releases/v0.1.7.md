# Codex Quota Widget v0.1.7

## 稳定连接状态与紧凑额度展示

- 修复启动阶段一次读取失败就显示“连接异常”的闪烁，单次失败改为连接中并自动重试，连续两次失败才显示异常。
- 额度卡片改为日历图标加剩余时间，鼠标悬停显示完整完成时间，减少正文信息密度。
- 剩余百分比按 25% 区间使用绿、紫、黄、红色，颜色同步到卡片边框、标签、百分比和进度条。
- 默认宽度从 350 缩小到 320 像素，保留自由缩放、标题栏控制和完整日期悬浮提示。
- 更新截图、README 和 UI 设计记录，并补充颜色阈值、瞬时失败和日期提示回归测试。

## 验证

- Release 编译零警告、零错误。
- 离线协议、错误恢复、语言切换、自动刷新、颜色阈值和日期格式测试通过。
- 中文/英文、窄/宽窗口、标题栏、置顶、最小化、最大化/还原、关闭行为截图和 UI 自动化测试通过。
- 真实账号读取和自动会员到期逻辑保持不变。
