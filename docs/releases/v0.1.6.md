# Codex Quota Widget v0.1.6

## 更小的玻璃界面

- 改为 350 像素宽的单列布局，移除侧边栏；根据额度内容适配高度，仍支持自由缩放。
- 新增可拖动标题栏，支持最小化、最大化/还原、置顶切换和关闭到托盘；默认置顶。
- Windows 11 22H2 及以上支持原生 Acrylic 背景模糊，搭配蓝紫渐变；不支持的环境使用不透明渐变。
- 保留完整到期日期和剩余时间，窄窗口自动换行；主操作改为带提示的图标按钮。
- 修复最大化覆盖任务栏及最小化后从托盘无法正常恢复的问题。
- 刷新期间禁用重复点击，连接状态和语言切换即时反馈。

## 验证与发布

- 增加标题栏、置顶、最小化/还原、最大化工作区和尺寸还原的 UI 回归测试。
- 增加英文布局截图、关闭隐藏和重新显示的隔离窗口测试。
- 完善自动审查、测试、本地提交、推送、版本发布及附件 SHA-256 回验流程。

## 下载说明

- `*-setup.exe` 为当前用户安装包；`*.zip` 为便携版，均自带 .NET 8 运行时。
- 关闭按钮隐藏到托盘，完全退出请使用托盘菜单。
- 安装包尚未签名；升级前请退出旧版。此版本未新增开机自启动或手动会员到期设置。
- 材质效果受系统透明效果设置影响；多显示器混合 DPI 尚未全面实测。
