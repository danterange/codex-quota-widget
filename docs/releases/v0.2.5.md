# Codex Quota Widget v0.2.5

## 单实例启动

- 小组件改为当前 Windows 用户会话内的单实例应用。
- 再次启动不会创建第二个窗口或第二个托盘图标；新进程会通知已有小组件恢复、置前，然后正常退出。
- 即使已有窗口被最小化或关闭到托盘，第二次启动也会把它找回；用户原先的长期置顶选择保持不变。

## 日间主题 ToolTip

- 修复日间主题下额度/更新时间悬浮提示出现深色空块、文字不可见的问题。
- ToolTip 内容使用独立的高对比度浅色文字样式，不再被日间正文的深色 TextBlock 样式覆盖。

## 验证

- 覆盖命名 Mutex、主实例激活事件、真实双进程启动/恢复窗口、日间 ToolTip 实际截图，以及既有的额度、Free、设置、窗口和安装回归。
