# v0.1.7 发布前验证

用户反馈启动时短暂出现“连接异常”随后变为“运行中”，并要求减少日期文本、增加 25% 颜色区间和重新发布安装包。

## 根因与修复

原逻辑把第一次 `QuotaReadException` 立即映射为错误状态；下一次定时刷新成功后清空错误，因此产生一次短暂误报。现在维护连续失败次数：第一次失败显示“连接中”，连续两次失败才显示“连接异常”，成功后清零并恢复运行中。错误详情仍保留在稳定异常状态的悬浮提示中。

额度时间正文改为日历图标和剩余时间，完整 `yyyy/MM/dd HH:mm:ss` 与倒计时保留在悬浮提示。剩余百分比按 `<25` 绿、`25–<50` 紫、`50–<75` 黄、`≥75` 红切换。

- UI 截图脚本：中文/英文、主界面/设置页、320 默认宽度、300 最小宽度、窄/宽窗口、日期图标、颜色区间、置顶和窗口控制通过。
